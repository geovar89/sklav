ΔΩΡΕΑΝ STORE LOCATOR ΧΩΡΙΣ API KEY

Περιλαμβάνει 492 καταστήματα.

Χρήση:
1. Άνοιξε το stores-map-free.html με Chrome ή Edge.
2. Απαιτείται σύνδεση στο internet μόνο για να φορτωθεί ο χάρτης και οι βιβλιοθήκες.
3. Δεν απαιτείται API key ή λογαριασμός Google.

Λειτουργίες:
- Ομαδοποίηση markers (clustering)
- Αυτόματο άνοιγμα ομάδων με zoom
- Spiderfy σε πολύ κοντινά σημεία
- Αναζήτηση
- Φίλτρο νομού και τύπου καταστήματος
- Sidebar με όλα τα καταστήματα
- Popup με ωράριο, τηλέφωνο, email, υπηρεσίες και οδηγίες
- Responsive εμφάνιση

Τεχνολογία:
Leaflet + Leaflet.markercluster + OpenStreetMap.

Σημείωση:
Για δημόσια εφαρμογή με πολύ μεγάλη επισκεψιμότητα, χρησιμοποίησε δικό σου tile provider ή self-hosted tiles σύμφωνα με την πολιτική χρήσης του OpenStreetMap.
